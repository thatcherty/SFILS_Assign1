# Create Database
```bash
use SFILS;
```
# Create Collections
```bash
db.createCollection("age_ranges");
db.createCollection("home_libraries");
db.createCollection("notification_pref");
db.createCollection("patron_types");
db.createCollection("patrons");
```

# Import Data
I used the data import feature for each document collection in MongoDB Compass

# Add Validations
## Age Range Collection 
```bash
db.runCommand( { collMod: "age_ranges",
   validator: {
      $jsonSchema: {
         bsonType: "object",
         required: [ "age_range_code", "age_range" ],
         properties: {
            age_range_code: {
               bsonType: "int",
               description: "must be a integer and is required"
            },
            age_range: {
               bsonType: "string",
               description: "must be a string and is required"
            }
         }
      }
   }
} );
```
